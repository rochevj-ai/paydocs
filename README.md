# PayDocs — Реєстр призначень платежів для ФОП/ТОВ

Простий веб-застосунок для генерації та обліку призначень платежів. Працює як один HTML-файл — без серверу, без бази даних, без реєстрації.

## ✨ Можливості

- 📋 Реєстр платежів з фільтрами та пошуком
- 🏢 Довідник контрагентів з IBAN-валідацією
- 🔢 Генерація номерів рахунків (3 формати)
- 📅 Перевірка вихідних днів
- 📊 Дашборд з лімітами витрат
- 📜 Журнал усіх змін
- 📤 Експорт в Excel, CSV, PDF
- 💾 **Збереження в localStorage** — дані не зникають після закриття
- 🔒 Резервні копії JSON (експорт/імпорт)

## 🚀 Запуск на GitHub Pages (безкоштовно)

### Крок 1 — Створіть акаунт GitHub
Перейдіть на [github.com](https://github.com) і зареєструйтесь.

### Крок 2 — Створіть новий репозиторій
1. Натисніть **"New repository"** (зелена кнопка)
2. Назва: `paydocs` (або будь-яка)
3. Поставте **Public**
4. Натисніть **"Create repository"**

### Крок 3 — Завантажте файли
Після створення репозиторію натисніть **"uploading an existing file"**:
- Завантажте `paydocs.html`
- Перейменуйте його в `index.html` (або залиште як є)
- Натисніть **"Commit changes"**

### Крок 4 — Увімкніть GitHub Pages
1. Відкрийте **Settings** вашого репозиторію
2. Знайдіть розділ **Pages** (в лівому меню)
3. У розділі **Source** оберіть **"Deploy from a branch"**
4. Гілка: **main**, папка: **/ (root)**
5. Натисніть **Save**

### Крок 5 — Ваш сайт готовий!
Через 1-2 хвилини сайт буде доступний за адресою:
```
https://ВАШ_НІКНЕЙМ.github.io/paydocs/
```

> ⚠️ **Важливо про дані:** Дані зберігаються в localStorage браузера кожного користувача окремо. Якщо ви хочете спільний доступ до одних даних — використовуйте функцію "Резервна копія" для передачі JSON-файлу між пристроями.

## 💾 Збереження даних

Дані автоматично зберігаються в `localStorage` браузера під ключем `paydocs_data_v1`.

| Що зберігається | Де |
|---|---|
| Всі платежі | localStorage |
| Контрагенти | localStorage |
| Журнал змін | localStorage |
| Статуси, ознаки перевірки | localStorage |

### Резервне копіювання
На сторінці **Експорт → Резервна копія**:
- **Завантажити JSON** — зберегти копію на комп'ютер
- **Імпортувати JSON** — відновити з копії
- **Очистити** — видалити всі локальні дані

## 🛠 Технології

- Чистий HTML + CSS + JavaScript (без фреймворків)
- [Inter](https://fonts.google.com/specimen/Inter) — шрифт
- [Tabler Icons](https://tabler-icons.io/) — іконки
- [SheetJS (xlsx)](https://sheetjs.com/) — експорт Excel
- `localStorage` — збереження даних

Щоб оновити застосунок — просто завантажте новий `paydocs.html` в репозиторій (кнопка **"Add file" → "Upload files"**). Ваші дані в localStorage залишаться.
